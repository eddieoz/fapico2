US-1518 — scripted acceptance page

Drives the request shapes identified by US-1521 against the attached authenticator over WebAuthn. Every case reports a machine-readable verdict. Human-gated cases need a physical button touch.

Which device this run is talking to: unknown
How to run: leave this page open, then press Run machine-gated cases. The runner polls this page for verdicts; a case that never reports is a FAIL, never a skip.

Machine-gated (no touch needed)

These exercise the transport the browser itself depends on. They cannot be faked: they issue real CTAPHID messages and read real replies.

Human-gated (each needs a touch)

Each of these is a real ceremony. The device enforces user presence (US-907) and this harness does not relax it, so each case waits for the button. A timeout is recorded as a FAIL.
